# Quick Symbol Lookup

## What This Is
A fast, alphabetical reference for mathematical symbols and notation. This is your go-to resource when you encounter an unfamiliar symbol and need to quickly understand what it means.

## When to Use This
- You see a symbol you don't recognize
- You need a quick reminder of what a symbol means
- You're reading mathematical content and want to verify symbol meanings
- You're looking for the most common interpretations of a symbol across different fields

## How This Works
Symbols are organized alphabetically, with each entry showing:
- **Symbol**: The mathematical notation
- **Common meanings**: Brief definitions across all fields where it appears
- **Field context**: Which mathematical areas commonly use this symbol
- **Cross-references**: Links to related symbols or concepts

## Structure
Each entry follows this format:
```
## Symbol: [symbol]
**Primary meaning**: [most common usage]
**Other meanings**: 
- [Field 1]: [specific meaning]
- [Field 2]: [specific meaning]
**See also**: [related symbols]
```

## Usage Tips
- This is for quick identification, not deep explanations
- For symbols with conflicting meanings, check the conflict-resolution reference
- For understanding mathematical context, use the field-identification reference
- Each entry provides just enough information to orient you, then points to more detailed resources

## Complementary Tools
- **[Detexify](https://detexify.kirelabs.org/)** - Can't find a symbol you're looking at? Draw it and get the LaTeX command! Perfect for when you can see a symbol but don't know how to type or search for it.
